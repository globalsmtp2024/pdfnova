Bookmarks, also called the document outline, are the clickable table of contents most PDF readers show in a side panel. When you combine several PDFs, they are the first thing to go missing, and in long reports, legal bundles or course packs they are often what makes the result usable.

## Why bookmarks break

A bookmark doesn't store a page number. It stores a reference to a specific page object inside the original file. When pages are copied into a new document, those page objects get new identities. A merge tool that copies pages without also rebuilding the outline leaves you with bookmarks pointing nowhere, or with no bookmarks at all.

There are two more subtle problems:

- **Named destinations.** Some bookmarks point to a named location instead of a page. The name has to be looked up in the source file before the page can be found.
- **Partial selections.** If you only include pages 1 to 3 of a ten-page file, bookmarks for pages 4 to 10 must be dropped, while their parents may need to stay so the structure still makes sense.

## A reliable approach

<Brand /> rebuilds the outline as part of the merge:

1. For each file, every bookmark is resolved to the page it really points to, including named destinations.
2. Bookmarks whose pages you excluded are dropped. A parent bookmark is kept if at least one of its children survives.
3. Each source file gets a new top-level bookmark, with its own outline nested underneath, so readers can jump straight to each original document.

You can switch either behavior off. Turn off **Add a bookmark for each file** for a flat outline, or turn off **Keep existing bookmarks** if the originals were messy.

## Tips for clean results

- **Name your files well.** The per-file bookmark uses the file name, so `03 - Witness statement.pdf` produces a far better outline than `scan0042.pdf`.
- **Order before you merge.** Drag files into place first; bookmarks follow the order of the pages.
- **Use page ranges for exhibits.** Include only the pages you need with ranges like `1-3, 5`. Bookmarks for excluded pages disappear automatically.
